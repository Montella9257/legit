# MEOW.DLL — Legit Client для Minecraft 1.21.4 Fabric

Нативный внутренний C++ / JNI + OpenGL3 клиент для **Minecraft 1.21.4 Fabric** с собственным тёмным неоновым интерфейсом (отдельным от графики Minecraft) и инжектом в уже запущенную игру через `inject.bat`.

---

## Быстрый запуск (Windows)

1. Запусти **Minecraft 1.21.4 Fabric** (подойдёт любой лаунчер: официальный, Modrinth, Prism, TLauncher и др.) и дождись открытия окна игры.
2. Скачай и запусти **`inject.bat`** (файл полностью самодостаточный — если папки `bin\` рядом нет, он автоматически распакует встроенные `Meow.dll` и `MeowInjector.exe` в `%LOCALAPPDATA%\MeowClient\bin` с проверкой SHA-256).
3. Переключись обратно в окно Minecraft — в правом нижнем углу появится уведомление `MEOW.DLL INJECTED • PRESS R-SHIFT`.
4. Нажми **`Right Shift` (`R-Shift`)**, чтобы открыть или скрыть меню.

Конфигурация автоматически сохраняется в `%APPDATA%\MeowClient\config.json`.

---

## Меню и интерфейс

- **Открытие / закрытие**: `R-Shift` (также `ESC` закрывает открытое меню).
- **Уникальная типографика**: встроенные шрифты **Unbounded Bold** (заголовки и логотип), **Exo 2** (интерфейс с поддержкой кириллицы и латиницы) и **JetBrains Mono** (числа, FPS, кулдауны и бинды).
- **Тёмный стиль**: обсидиановая тема `#0A0B10` с градиентными акцентами (`Sakura`, `Cyber`, `Rose`, `Mint`), векторной эмблемой кота, анимированными переключателями, слайдерами и биндами на каждую функцию.

## Разделы и функции

### Visual
- **Player ESP** — 2D-рамки по углам, полупрозрачная заливка, полоса здоровья, никнеймы и дистанция до игроков (3D→2D проекция с интерполяцией по `tickDelta`).
- **Tracers** — линии к ближайшим игрокам.
- **Target HUD** — карточка цели под прицелом (имя, плавное HP, индикатор урона, дистанция и статус `CRIT WINDOW`).
- **Crit & Cooldown Ring** — компактное кольцо перезарядки атаки и индикатор готовности крита вокруг прицела.
- **Fullbright** — повышение гаммы в темноте с восстановлением исходного значения при выключении.

### PveFarm
- **Mob Trigger** — автоматическая атака мобов в прицеле (фильтр враждебных мобов, кулдаун, умные криты в прыжке).
- **Auto Fish** — автоматическая подсечка при поклёвке поплавка и перезаброс с настраиваемой случайной задержкой.
- **Auto Sprint** — авто-спринт (автоматически приостанавливается в момент крита TriggerBot).
- **Auto Eat** — переключение на еду в хотбаре при снижении голода/HP и возврат слота.

### PvP
- **TriggerBot** — быстрая легитная атака игроков при наведении прицела с критическими ударами (`1.5x` урон):
  - **Crit Mode**:
    - `Smart` — на земле бьёт сразу по кулдауну, в воздухе ждёт падения (`fallDistance > 0`), чтобы каждый удар в прыжке был критом.
    - `Only Crits` — атакует только при выполнении условий критического удара.
    - `AutoCrit` — сам подпрыгивает на земле перед готовностью кулдауна и бьёт в фазе падения.
  - **Sprint Reset for Crits (Server Sync)** — сбрасывает спринт и отправляет пакет `STOP_SPRINTING` перед ударом, чтобы сервер 1.21.4 гарантированно засчитывал крит даже при зажатом беге/AutoSprint.
  - **Attack Cooldown** (`0.85–1.00`, по умолчанию `0.92` для максимальной скорости с сохранением критов), **Reaction Jitter (ms)**, **Reach Limit**, **Weapon Only**, фильтры невидимых / тиммейтов / креатива.
- **Aim Assist** — плавная легитная доводка прицела в заданном FOV.
- **Sprint Reset (W-Tap)** — короткий сброс спринта после удара для комбо.
- **Jump Reset** — легитный прыжок в тик получения урона для снижения откидывания.

## Архитектура проекта

- `inject.bat` — скрипт запуска инжектора.
- `src/injector/main.cpp` — Windows x64 инжектор (`LoadLibraryW` с поддержкой кириллических путей, поиск окна `GLFW30` / `Minecraft 1.21.4`, защита от повторного инжекта).
- `src/dll/mc_mappings.hpp` — проверенные Intermediary-маппинги **Minecraft 1.21.4 Fabric**.
- `src/dll/jvm_bridge.*` — JNI-мост с поиском `KnotClassLoader` Fabric Loader и безопасными `PushLocalFrame`/`PopLocalFrame` кадрами.
- `src/dll/hooks.*` — хуки `wglSwapBuffers` (OpenGL3 Core Profile `#version 150`), `WndProc` (`VK_RSHIFT` / блокировка ввода игры при открытом меню), `SetCursorPos` / `ClipCursor`.
- `src/dll/modules.*` — логика модулей `Visual`, `PveFarm`, `PvP` и 3D→2D проекции.
- `src/dll/ui.*` & `src/dll/embedded_fonts.*` — тёмный ImGui-интерфейс и сжатые встроенные шрифты.

## Сборка из исходников

Готовые x64 бинарники уже лежат в `bin/Meow.dll` и `bin/MeowInjector.exe`.
При желании пересобрать вручную:
- **На Windows**: запусти `build.bat` (поддерживает `zig` или `MinGW g++`).
- **Кросс-компиляция на Linux**: `./build_zig.sh`.
